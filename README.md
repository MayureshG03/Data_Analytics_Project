# Cosmetics Customer Behavior Analysis

This project analyzes customer behavior in the cosmetics industry using **Excel**, **Python (Jupyter Notebook)**, and **Tableau**. It focuses on understanding customer churn, retention patterns, lifetime value, delivery satisfaction, product preferences, and purchasing behavior. The project demonstrates a full Data Analytics workflow—from raw data to dashboards.

---

## 📁 Project Structure

### **1. _DataSet_**
Contains:
- **Raw_Data_Set** 
- **Clean_Data_Set (Excel)**
  
Includes:

- Duplicate removal  
- Missing value treatment  
- Column standardization  
- Basic cleaning
- Churn flag creation  
- Risk segmentation  
- Standardized formats  


---

### **2. _Clean_Raw_DataSet**
Contains:
- Cleaned dataset generated using **Jupyter Notebook**
  
Includes:

- Missing value handling  
- Outlier treatment  
- Duplicate removal    
---

### **3. _Jupyter_NoteBook**
Contains:
- **Cosmetics_Data_Cleaning (.ipynb)**
- **Cosmetics_EDA(.ipynb)**
- **Visualization_Notebook(.ipynb)**
  
Includes:

- Data cleaning workflow  
- Statistical summaries  
- EDA visualizations using `matplotlib` and `seaborn`

---

### **4. Tableau_DashBoard**
Contains:
- Screenshots of Tableau dashboards
   
Dashboards include:

- Customer Experience And Value Metrics 
- Geographic Demand Distribution
- KPI 
- Order And Category Performance 
- Risk, Revenue And Age Segmentation
